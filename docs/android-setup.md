# Android APK setup (Phase 5)

Status: **scaffolded, blocked on Android SDK** — run these steps on a machine with enough disk space (≈4 GB for SDK + NDK).

## What the APK does / does not do

- ✅ On-device, self-contained: search/stream/download the **open/CC catalog** (Audius natively, Wikimedia Commons, Jamendo with your free `client_id` in Settings)
- ✅ Same React UI / Liquid Glass & PixelOS Material themes, rusqlite library, local recs engine
- ❌ The mainstream catalog (NetEase/QQ/Kuwo/Migu…) is NOT bundled — `musicdl`'s native deps (PyAV/FFmpeg, curl-cffi, nodejs-wheel) have no Android wheels. Use one of:
  - **Termux backend** on the phone (`pip install musicdl && python -m app.main --port 8787`), then Settings → Backend URL = `http://127.0.0.1:8787` (accepts `CODECI_BACKEND_TOKEN` for LAN/QR-secured access), or
  - A LAN/NAS machine running `codeci-backend` (reachable over Wi-Fi), or
  - A home server behind your Cloudflare domain (TLS + `CODECI_BACKEND_TOKEN`).

## Prerequisites

1. JDK 17+ (21 works).
2. Android SDK — either install [Android Studio](https://developer.android.com/studio) (recommended) or the [command-line tools](https://developer.android.com/studio#command-tools):
   ```
   cmdline-tools/latest/bin/sdkmanager --install "platform-tools" "platforms;android-36" "build-tools;36.0.0" "ndk;27.2.12479018"
   ```
3. Rust targets:
   ```
   rustup target add aarch64-linux-android armv7-linux-androideabi i686-linux-android x86_64-linux-android
   ```
4. Set `ANDROID_HOME` / `ANDROID_SDK_ROOT` (e.g. `C:\Users\you\AppData\Local\Android\Sdk`).
5. Gradle wrapper is generated by `tauri android init` (no separate install needed).

## Build & run

```powershell
# from repo root:
.\frontend\node_modules\.bin\tauri.cmd android init   # scaffolds gen/android from src-tauri/
.\frontend\node_modules\.bin\tauri.cmd android dev     # deploy to connected device/emulator
.\frontend\node_modules\.bin\tauri.cmd android build   # release APK/AAB
```

Icons were already generated under `src-tauri/icons/android/` (mipmap set via `tauri icon`).

## Testing matrix (when SDK lands)

| Check | Command |
|---|---|
| Debug build installs | `tauri android dev` on emulator (Pixel 7, API 34/36) |
| Audio plays | Audius stream in webview — may need `mixedContentMode` / https (all Audius URLs are https ✓) |
| Download to Music | download manager writes via reqwest → app-private storage; expose via "share/move" in v1.1 |
| Offline library | `.db` in app-private dir; persists across launches |
| Themes | Liquid Glass perf on mid-range GPU; fall back to PixelOS if janky |

## Termux backend (optional, full catalog on the phone)

```bash
pkg install python ffmpeg
pip install musicdl fastapi uvicorn httpx python-multipart
git clone https://github.com/xonix97/codeci ~/codeci
cd ~/codeci/backend && python -m app.main --port 8787
```
Then in the APK: Settings → Backend URL `http://127.0.0.1:8787` → Search gets NetEase/QQ/…; optionally set `CODECI_BACKEND_TOKEN=some-long-random-string` before start and paste it in Settings.
